# GraphQL upload example

A [gqlgen](https://gqlgen.com) server whose mutations take files as the `Upload` scalar of the GraphQL multipart request specification and store them through `contrib/gqlgen` under an `upload.Policy`: `uploadFile` and `uploadFiles` on a memory disk, `setAvatar` as a records row attached to the signed-in user, `avatar` to read it back. This directory is a separate Go module (`github.com/ubgo/filesystem/examples/gqlgen`) so the main examples module does not depend on gqlgen. The guide is [GraphQL uploads](../../docs/integrations/graphql.md).

## Run it

```sh
cd examples/gqlgen
go run .           # http://localhost:8195/graphql
go test ./...      # real multipart requests through the server
go generate ./...  # regenerates graph/generated.go after a schema change
```

Everything is in memory (one memory disk, the records tables in in-memory SQLite) and gone on restart. The `X-User` header stands in for authentication. Ctrl+C or SIGTERM shuts the server down gracefully.

## Walkthrough

```sh
printf 'quarterly numbers\n' > report.txt
printf '<!doctype html><script>alert(1)</script>' > page.txt
Q='{"query":"mutation($file: Upload!) { uploadFile(file: $file) { key filename contentType size sha256 } }","variables":{"file":null}}'
A='{"query":"mutation($file: Upload!) { setAvatar(file: $file) { id filename uploadedBy } }","variables":{"file":null}}'
M='{"0":["variables.file"]}'
curl -s localhost:8195/graphql -F operations="$Q" -F map="$M" -F 0=@report.txt
curl -s localhost:8195/graphql -F operations="$Q" -F map="$M" -F 0=@page.txt
curl -s localhost:8195/graphql -H 'X-User: alice' -F operations="$A" -F map="$M" -F 0=@report.txt
curl -s localhost:8195/graphql -F operations="$A" -F map="$M" -F 0=@report.txt
```

## Files

| File | What it holds |
|---|---|
| `go.mod` | The separate module, with `replace` directives back to the library's modules and gqlgen as a `tool` |
| `gqlgen.yml` | gqlgen's configuration: `Upload`, `StoredUpload` and `FileRecord` mapped to the library's types |
| `graph/upload.graphqls` | A verbatim copy of `fsgql.Schema`; a test fails if it drifts |
| `graph/schema.graphqls` | The example's types, queries and mutations |
| `graph/resolver.go`, `graph/schema.resolvers.go` | The resolvers, storing every upload through `fsgql` |
| `graph/generated.go`, `graph/model/` | Generated by gqlgen; do not edit |
| `main.go` | The server: disk, records store, transports, error presenter, the stand-in authentication |
| `main_test.go` | Multipart requests per the specification: one file, a refused file, a list all or none, an avatar as a record |
